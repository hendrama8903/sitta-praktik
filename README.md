# Tugas 1 Pemrograman Berbasis Web

## Deskripsi
Repository ini berisi tugas pertama untuk mata kuliah **Pemrograman Berbasis Web**.  
Project ini dibuat sebagai latihan dasar dalam pengembangan aplikasi/web berbasis teknologi web.

## Tujuan
- Memahami dasar pemrograman web
- Menerapkan struktur project web sederhana
- Mengimplementasikan konsep HTML, CSS, dan JavaScript (sesuaikan jika digunakan)

## Fitur
- Tampilan halaman web sederhana
- Implementasi elemen dasar web
- Struktur project untuk pembelajaran

## Teknologi yang Digunakan
- HTML
- CSS
- JavaScript

## Struktur Project
```bash
project-folder/
│── index.html
│── style.css
│── script.js
└── README.md
```

## Cara Menjalankan
1. Clone repository ini:
```bash
git clone https://github.com/username/nama-repository.git
```

2. Buka folder project

3. Jalankan `index.html` di browser
